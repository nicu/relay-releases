Keyboard shortcuts

This page is made from Relay itself, so it always matches the version it documents. You can change any of these in Settings › Keyboard; this page lists the defaults.

⌘ is Ctrl on Windows and Linux, ⌥ is Alt and ⇧ is Shift. Shortcuts without ⌘ act in the view that has focus (a list, the board, the open issue), never while you type in a field.

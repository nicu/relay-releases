Settings

This page is made from Relay itself, so it always matches the version it documents. Open Settings with ⌘, (Ctrl+, on Windows and Linux), or find any of these in ⌘K by its name.

App​

General​

How Relay starts and behaves on your computer.

Startup

  • Open at login: Start in the background when you log in.
  • Search from anywhere: Opens Go to issue over any app, while Relay runs: comments, operators and all.
  • Open to: The screen you see first.
  • Dock badge: What the number on the app icon counts.

Region

  • Week starts on: Used by the Timesheet and worklog totals.
  • Time format
  • Working hours: Gaps outside these hours are never suggested.
  • Break: Taken within working hours; the rest is a working day, the Timesheet’s target and the rules’ working day.
  • Working days: The days of the week you work.

Days off

  • Days off: Holidays and leave: not working days.
  • Calendar feed: Your calendar’s private iCal address (Google: Secret address in iCal format; Outlook: a published calendar’s ICS link). Days it shows you out of office are days off.
  • Out of office: Read hourly and when you Refresh.

Updates

  • Check for updates automatically: At startup and every few hours, from GitHub. Nothing downloads until you ask.
  • Version

Appearance​

Theme, density and what the sidebar shows.

Theme

  • Theme
  • Colour: Selection, primary buttons and highlights, as picked: light colours take dark text. With tinted surfaces, the hue everything leans to.
  • Surfaces: Neutral greys, a warm cream, or tinted: surfaces, statuses and labels leaning to the colour.
  • Clay: Soft raised surfaces and sunken fields instead of lines, rounder corners and pills.

Interface

  • Density: Compact fits more rows on screen.
  • Font size
  • Show projects and epics in the sidebar
  • Show counts in the sidebar
  • Group tabs by epic: A new tab joins its epic’s group. Tabs you move yourself stay where you put them.
  • Open issues in preview: An opened issue shows without a tab, and the next one takes its place. Open in tab keeps it.

Notifications​

When the app is allowed to interrupt you. What counts as worth it is decided by your rules.

Desktop

  • Notify for: Inbox items: whatever reaches Inbox, and rules with a Notify action.
  • Sound
  • Quiet hours: Notifications wait, then arrive as one summary.
  • Morning digest: One summary instead of overnight pings.

Rules

  • Notification rules: What reaches Inbox and what notifies lives on the Rules page.

Timesheet​

How timesheet drafts share out a day from your activity.

Drafts

  • Worklog steps: Time logged or changed here rounds to the nearest step; so do timesheet drafts. Worklogs already in Jira keep theirs.
  • Never draft time for: Projects or issues, comma-separated: SUPPORT is every SUPPORT issue, PAY-12 just that one.
  • Ignore changes to: Fields, comma-separated, whose changes are no signal.

Signal weights

  • Commit: A commit of yours naming the issue.
  • Comment: A comment you wrote.
  • Status move: Each further move the same day counts half the one before.
  • Created: An issue you created.
  • Assigned to you: Fades like status moves.
  • Hand-off: Assigning it to someone else; only alongside other work that day. Fades like status moves.
  • Other field change: Fades like status moves.

Repositories​

Your local clones, for this account. Relay reads them and never changes them.

Linked

  • Repositories: Activity and timesheet drafts read your commits in them; the Assistant reads their code (with several, a chat about an issue reads the ones whose branches or commits name it, or asks which).
  • Your commit emails: Comma-separated. Your commits are the ones by these or by the repository’s git user.email; git’s config stays as it is.

Assistant​

Assistant​

What the Assistant offers you by default. Everything here can be changed per chat.

Quick actions

  • Quick actions

Code

  • Use code from repositories: Lets answers and drafts read branches, commits and files linked to the issue.

Changes

  • Assistant can: Read & write lets it make timesheet drafts, change issues, comment, log work and triage Inbox, as an MCP client with write access can.
  • Ask before changes: Its changes wait in Inbox for your OK. Timesheet drafts and triage run directly: drafts stay here until you accept them.

Model​

The assistant is optional. Everything else works without it.

Assistant

  • Provider: Claude or OpenAI (GPT, Codex) with your API key, or any server with an OpenAI-compatible API, on this computer or remote. Off turns the Assistant off.

Connection

  • Endpoint: The server’s OpenAI-compatible base URL, usually ending in /v1.
  • Model
  • API key
  • Status
  • What leaves this computer

Speed

  • Answer times: How long the model in use took to answer lately, whole turns: compare models or settings.

MCP & integrations​

Let agents and other tools use Relay.

MCP server

  • Local MCP server: Agents like Claude Code, Claude Desktop, Codex and ChatGPT can read issues, triage Inbox and work with rules.
  • Status
  • Ask before write tools: Rule changes from MCP wait in Inbox for your OK. Triage runs directly.
  • Allow Jira searches: Lets clients run JQL on Jira with your account, beyond the issues stored here.
  • Port: Local only (127.0.0.1).

Clients

  • Clients: Each client gets its own token; remove one to cut it off. ChatGPT’s chats can’t reach a server on this computer; its desktop app uses Relay through Codex.

Tools

  • Tools: What clients may call. A tool ticked off isn’t listed to any client; Relay’s Assistant keeps all of them.

Open in

  • Default app: Where Open in…’s shortcut and the issue header’s button start a conversation.
  • Claude Code opens in: Claude Desktop’s Code tab, or a terminal running the claude command.

Data​

Data & privacy​

Everything is stored on this computer.

Storage

  • Local database
  • Cache attachments: Keeps images and videos you view for offline viewing. Other files open in Jira.
  • Attachment cache limit: The least recently viewed go first.
  • Cached attachments
  • Clear data: Pick what to clear: copies of Jira data download again; your own data is gone.

Reset

  • Reset all settings: Keeps your Jira connection and rules.
  • Sign out and remove all data
